## origin/main 引用消失之谜——已根治（02:40）

- 现象：push/fetch 均报成功，但 `.git/refs/remotes/origin/*` 反复消失，status 显示 `[gone]`，rev-parse origin/main 失败；手写文件却稳定存活。
- 根因：fetch/push 结束时 git spawn 分离进程 `git maintenance run --auto`（gc），其 pack-refs 步骤先删 loose 引用、再写 packed-refs——在沙箱里该分离进程被中途杀掉，packed-refs 永远写不成，引用就"蒸发"了。
- 修复（仓库本地 config）：`maintenance.auto=false` + `gc.auto=0`。代价仅是无自动 gc，本项目体量可忽略，需要时在用户终端手动 `git gc`。
- 验证：关闭后 fetch 的引用稳定落盘，status 干净 `## main...origin/main`。
- 踩坑：沙箱无法完成 GitHub OAuth 弹窗认证，push 认证必须用户终端执行；WorkBuddy 内置 Git Bash 无 connect.exe，须用 D:\software\Git 的。
