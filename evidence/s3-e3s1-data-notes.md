## 3. 数值推导（GDD 未给的字段）

### 3.1 角色：取 §3.6 表格 Lv1 列 + 正文"每级 +X"

按正文推算的 Lv5 与 GDD 表格右列的对照（**加粗为不一致**）：

| 角色 | 项 | GDD 表格 Lv5 | 按正文推算 | 差 |
|---|---|---|---|---|
| 凯尔 | 全部 | 280/22/26/4/18/12 | 280/22/26/4/18/12 | 全等 ✓ |
| 莉娜 | HP | 190 | 212 | **+22** |
| 莉娜 | DEF | 12 | 14 | **+2** |
| 莉娜 | MP/MAG/ATK/SPD | 62/24/5/10 | 62/24/5/10 | 全等 ✓ |
| 莫娜 | HP | 225 | 223 | **−2** |
| 莫娜 | MAG | 20 | 30 | **+10** |
| 莫娜 | DEF | 14 | 15 | **+1** |
| 莫娜 | MP/ATK/SPD | 52/7/11 | 52/7/11 | 全等 ✓ |

**取正文的理由**：表格右列无法由"逐级定值整数"达成——莉娜 HP +110/4 = 27.5、莫娜 HP +130/4 = 32.5、莉娜 DEF +6/4 = 1.5、莫娜 DEF +7/4 = 1.75，均为非整数，与 §3.6"逐级定值（不做随机成长）"矛盾。正文的"每级 +X"是逐级可实现的规格，故取正文。

MAG 的 `+3/+5` 归属取 **莉娜 +3 / 莫娜 +5**：莉娜 12→24 与表格完全吻合；反取（莉娜+5/莫娜+3）则两个都不吻合。

## 5. 调校观察（不改数据，留给 GDD §7 的 12h 平衡）

1. **伤害公式对高 DEF 角色过度敏感**：物理伤害 = max(1, ATK×2 − DEF×1.5)。凯尔 Lv1 DEF 10 → 飞蛾（ATK 8）只打出 **1 点**伤害（0.8% 最大 HP），远低于 §3.6 的 8%~15% 口径。对脆皮（莉娜/莫娜）命中率在 8.4%~10.6%，符合口径。**结论**：§3.6 的 8%~15% 只对脆皮成立；剑士作为肉盾近乎免伤。若希望剑士也有压力，需上调敌人 ATK 或下调 DEF 系数——属文策渊/数值平衡范畴，本 Story 按 GDD 明文的 ATK 值填表。
2. **B1 可能一回合结束**：凯尔普攻 23.5 + 莉娜普攻 5.5 + 莫娜普攻 9.5 = 38.5 ≥ 飞蛾 30 HP；莉娜火球（Lv1 即可用）≈32 可单杀。教学场"无压力"符合 §7 意图，但玩家可能来不及体验"攻击/道具"就被法术带走。若 B1 要承载教学，建议 B1 前锁技能或提高飞蛾 HP——由文策渊裁决。
3. **逃跑成功率**全在 30~95% 区间内（我方均 SPD 11）：B1 80% / B2 76% / B3 77.5% / B4 74% / B5 72%（B5 禁用逃跑，仅作参考）。
