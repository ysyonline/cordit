## 6. 遗留观察项（移交门审 / B 段，非 A 段验收阻塞项）

4. **`_ev` 系其余事件仍不过信号**（ai/heal/item/defend 等）：D6/D7 已按需接线；若 B 段演出（攻击动作/道具动画）需消费其余事件，沿用"产生处 emit"模式或届时另立 ADR 统一修 `_emit_all`。
5. **实机观感抽查明细**（用户目检清单）：蓄力横幅位置/字号、阵亡灰度、浮动数字节奏（18px/0.65s）、逃跑提示位置、结算滚动条样式——各卡证据档 §遗留风险 已分别列出。
6. **GUT 断言 API 备忘**：GUT 9.7.1 无 assert_ge/assert_le（GdUnit4 名），用 assert_gt/assert_lt/assert_true 显式比较（A5 首轮误用已记录在案）。
