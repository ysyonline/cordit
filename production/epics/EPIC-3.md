### E3-S3 四指令 + 三结局结算 · 6h
- 需求依据：战斗 GDD §3.2（四指令规则：防御 ×0.5+回 MP5、技能/道具每回合限 1）、§3.5（胜利/失败/逃跑结算；Boss 禁逃菜单置灰）。
- 做什么：指令状态机（菜单→目标→结算→队列推进，全程可取消）；逃跑为每角色各自指令，任一成功整队脱离。
- 验收标准：
  - [x] 四指令全部可用，MP 不足置灰但攻击/防御永远可用（§3.6 之 4，防软锁）
  - [x] 道具耗尽显示提示且可取消返回（§3.6 之 5）
  - [x] 逃跑成功率按公式计算（70% + SPD 差 ×2%，钳 30-95%）
  - [x] 我方全灭发生在敌方结算途中时立即中断进失败流程（§3.6 之 7）
  - [x] 失败读档此阶段允许占位提示（真读档 E4-S7 接管）
