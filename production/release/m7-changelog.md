## 玩起来有什么不同

### 战斗：以前是"走过去"，现在是"要打一打"

这一版动了五场战斗里的四场。改的不是伤害公式，只改了敌人的血量和编组——所以操作手感你不会陌生，变的是**战斗的长度和你必须做的决定**。

**遗迹一层的第一场群战（火蜥 + 冰晶 + 飞蛾）**变化最明显。以前两个回合就结束，全队几乎没掉血，你甚至不会注意到这是一场"消耗战"。现在它要打五个回合左右，主角的血量会被真正压下来，你得开始考虑"这回合是抢输出还是先奶一口"。

更重要的是属性陷阱现在真的有牙齿了：**火蜥抗火、冰晶抗冰**。如果你一路火球推过来，会发现打到火蜥身上伤害被砍半——正解是给莉娜换冰锥。这场战斗的设计意图就是逼你在冰和火之间来回切。

**遗迹二层的守卫（精英）**以前有个尴尬问题：它还没来得及放出群击和毒击就被打死了，等于它的两套教学招式白设计。血量上调后，你会稳定看到它至少各放一次——群击逼你开群愈，毒击逼你净化或者掏道具。

**三层的 Boss（遗迹核心）**是这版改动最大的一场。它有一招"蓄力 → 下回合重击"，设计上是要你看懂预告条、然后按下防御硬吃这一下。以前它四回合就倒下，蓄力刚起手人就没了，这招等于不存在。现在能打六个回合，蓄力会触发两次——**你真的有时间看到"它在蓄力"，也真的需要决定要不要防**。

普通战斗和 Boss 战的时长现在落在设计目标区间内（普通战 2–4 分钟，Boss 战 5–8 分钟）。

**第一场（道路飞蛾）和第二场（雷壳甲虫）没有改。** 这两场是教学场，本来就该简单：一场教你攻击和用道具，一场教你打弱点。模拟器验证下来数值合理，就不动了。

### 剧情：三段占位文字换成了成稿

三处地方以前能看到 `【P2 遗迹入口·占位】`、`【P3 战前·占位】`、`【P3 钩子·占位】` 这样的方括号标记——那是我们留给自己的待办。这一版全部替换成正式文本：

- **遗迹入口**：进遗迹那段氛围实写了，莉娜会告诉你"魔力不是变浓了，是在往一个方向流"——这是给你的探索引导。
- **Boss 战前**：石棺开启、暗红核心登场的那段前置演出。
- **通关结尾**：核心熄灭之后发生了什么，以及最后那句钩子。这里不剧透，只说一句：它留的是一个**未解之谜，不是没写完的剧情**。

另外这三段现在**主角队有头像了**。之前的版本里这些对话没有指定头像窗，画面左侧是空的。

### 流程：两个会卡住你的 bug 修掉了

- **在道路上打完敌人，回不去道路了。** 道路地图上三个敌人记着"打完回哪张图"，但写的地图名是简称，系统的地图存在性校验不认简称，直接拒绝跳转。现在改成完整路径，打赢后能正常回到道路继续走。
- **走正常路线进道路 / 遗迹二层时，队员聊天对话不显示。** 只有从某条特定路线进图才正常。根因是对话播放器没有正确交给事件执行器，对话动作被整段跳过。现在从正常入口进图，队员聊天会正常弹出来。

## 这一版的完整变更

### 战斗数值

| 位置 | 改动 | 为什么 |
|---|---|---|
| 遗迹一层 · 火蜥 | HP 55 → 100，ATK 12 → 13，DEF 4 → 8 | 原配置两回合结束、全队近满血，无消耗感 |
| 遗迹一层 · 冰晶 | HP 50 → 95，ATK 11 → 13，DEF 7 → 9 | 同上 |
| 遗迹一层 · 编组 | 飞蛾 2 只 → 3 只 | 敌方行动轮次 +1，把血线压力逼出来 |
| 遗迹二层 · 遗像守卫 | HP 240 → 360 | 原来 3 回合击杀，群击/毒击来不及放；现约 5 回合，两套招式各至少触发一次 |
| 遗迹三层 · Boss 遗迹核心 | HP 480 → 600 | 原来 4 回合击杀，蓄力→重击循环来不及展开；现约 6 回合，蓄力触发 2 次 |
| 道路飞蛾 / 雷壳甲虫 | **不改** | 教学场，模拟器验证合理 |
| 角色成长 / 敌人 ATK 与 DEF / 技能倍率 | **零改动** | 只动 HP 一项，避免"动一处、全场重调" |

所有受击数值都落在设计文档的分档区间内（剑士 4–10%、辅助 8–14%、术士 10–16%），不会出现"一下秒人"或"挠痒痒"。

### 剧情与文本

- 三份剧情对话实写（`story_p2_ruin_enter`、`story_p3_boss_front`、`story_p3_finale`），移除全部占位标记
- 三段对话补上头像差分（`rina_normal`），主角队不再空着头像窗
- 全量对话文本 **202 条**，在设计预算上限 350 条以内

### 缺陷修复

- 道路地图敌人战后回图被拒（地图名简称 → 完整路径）
- 道路 / 遗迹二层聊天点走正常入口时对话被跳过（对话播放器未注入事件执行器，已加幂等守卫防重复注入）

### 测试

- GUT 全量 **514/514 PASS**（M6 时为 513/513，本版净 +1 条回归用例：覆盖"正常入口进图"路径）
- 战斗数值断言随调校同步更新

## 已知问题（这一版就有，不是 bug 报告对象）

1. **没有声音。** 宝箱开启等处挂了音效路径，但音频文件本身还没做。不会报错、不影响流程，只是安静。
2. **敌人和队友是纯色方块。** 俯视地图上玩家是金黄、NPC 是青灰、敌人是暗红，战斗里也是色块。这是垂直切片的既定范围——**先把玩法跑通，美术素材是下一阶段的事**。
3. **中文显示依赖系统字体。** 不同 Windows 机器上字形可能略有差异。如果看到方框（豆腐块），请告诉我们具体是哪一屏。
4. **单存档槽。** 覆盖式保存，没有多档位。
5. **窗口固定 640×360 整数倍拉伸。** 在高分辨率显示器上是小窗，全屏会有黑边。

## 怎么运行

1. 解压后保持 `轨迹残响.exe` 和 `轨迹残响.pck` **在同一个文件夹里、文件名都不要改**（这两个是配套的，改任一都会启动失败）。
2. 双击 `轨迹残响.exe`。首次启动会在系统用户目录创建存档文件夹。

**操作**：`WASD` 移动 · `Z` 或 `E` 交互 · `C` 打开菜单 · `X` 或 `Esc` 取消 · `M` 调试面板

**通关时长**：约 30 分钟。

## 反馈回收

试玩后最想听到的三件事（这就是我们内部说的"三问测试"，决定这一版算不算通过）：

1. **你在哪一场战斗里第一次主动按下了防御？** 如果没有——哪一场你觉得"其实该防但我没防"？
2. **你有没有主动切换过攻击目标或技能属性？** 遗迹一层那场（火蜥 + 冰晶 + 飞蛾），你是一路火球推过去的，还是中途换了冰系？
3. **打完遗迹二层那个守卫之后，你脑子里冒出的第一句话是什么？** 这句最真实就好，不用替我们客气。

另外欢迎随手记：哪里卡住了、哪段对话看不懂、哪个数值让你觉得"这不讲道理"。
