## 二、怎么在 2-3 分钟内拍到 B4/B5/结尾（选一条）

整段切片约 30 分钟，B4+B5+结尾本身就要 10 分钟以上。**实时从头录到尾再压到 3 分钟是不现实的**，二选一：

### 方案 A（推荐 · 省时，约 15 分钟完成录制）

1. **先不录屏**，正常玩到**遗迹二层、B4（遗像守卫）之前**——路上该打的 B1-B3 正常打掉（**不要全逃跑**，否则进 B4 时等级不足会打得很痛苦）。
2. 走到 B4 前，在**遗迹二层入口**手动存一个档（主菜单 → 存档）。
3. **开始录屏**：回主菜单 → **读档** → 落到遗迹二层 → 手动操作打 B4 → 上三层打 B5 → 一直玩到结尾字幕/最后一句台词。
4. 收尾停录。

> 这仍然满足「main.tscn 正常入口 + 手动操作」：读档是正常入口的一部分，战斗全是真人操作、非确定性驱动。只是把前期 15 分钟的赶路快进掉了。

### 方案 B（完整 · 需剪辑）

从头录到尾（约 25-30 分钟），后期剪成 2-3 分钟：前段留 5-10 秒交代 P0 与地图推移，中段快剪，**B4 / B5 / 结尾三段完整保留不剪**。

## 四、录制步骤

1. 打开 Godot 编辑器（winget 版），载入 `D:\code\cordit`，**F5 运行主场景**。
   （或命令行：`Godot_v4.7.2-stable_win64_console.exe --path "D:\code\cordit"`）
2. 确认游戏窗口焦点在本机，开启 Win+G 或 OBS，1080p / 30fps。
3. 按 §二选定方案（**推荐方案 A**），按 §三 分镜顺序手动游玩。
4. **边玩边留意**：任何报错弹窗、卡死、穿墙、文字溢出、数字异常（负数/NaN）都要记下来——这些比视频本身更有价值。
5. 停录，导出为 `evidence/m7-gameplay.avi`。
6. 把控制台输出另存为 `evidence/m7-recording.log`，确认 **零 ERROR**。

## 五、常见坑（前六段视频踩过的）

| 坑 | 规避 |
|---|---|
| 录到一半发现没开录 / 存到了奇怪目录 | 录 3 秒后暂停回放确认一次再继续 |
| 全程没打 B1-B3 就冲进 B4 → 等级不足、打得极痛苦 | 方案 A 的赶路阶段**正常打完 B1-B3**，保证 Lv3/Lv4 进 B4/B5 |
| Boss 想逃跑发现跑不掉 | **这是设计**，Boss 战禁用逃跑（菜单置灰）。别当 bug 报 |
| 结尾按太快，钩子一闪而过 | 最后一句台词前**放慢按键**，让「第一个，还有五个。」在画面上停留 2 秒以上——这是本视频最重要的 2 秒 |
| 视频体积过大 | M5/M6 分别 320MB / 336MB 属正常（LFS 已配），不必压制 |
| 走成了 auto-demo 链路 | **别用 `evidence/_m*_auto_demo.tscn`**，从 `main.tscn` 进 |
