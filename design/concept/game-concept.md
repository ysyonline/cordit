# 游戏概念文档 · 《轨迹残响》垂直切片（暂定名）

> 作者：文策渊（design-strategist）｜阶段：概念设计｜汇编：游承峰（team-lead）
> 状态：初稿，待用户对 3 个决策点拍板后定稿

---

## 1. 一句话概念

**一款用现成素材包制作的 2.5D 战术回合制 JRPG 垂直切片——在小而密的一座边陲小镇与遗迹中，体验"每一场战斗都有选择、每一段对话都有性格"的空之轨迹式叙事冒险，约 30 分钟流程，用于验证开发者能否独立完成一款完整 JRPG。**

电梯陈述（30 秒版）：
"我想做《空之轨迹》那种感觉的 JRPG：一支小队在一张充满细节的地图上旅行，战斗是回合制的但有位置和属性弱点的博弈，剧情靠角色对话慢慢展开。这个垂直切片包含一座小镇 + 一段遗迹 + 三名角色 + 约 30 分钟的完整剧情段落，用现成素材包在 3-4 个月、每周 5-10 小时的业余时间里做完。它存在的目的不是商业发布，而是回答一个问题：**我一个人能不能把一款 JRPG 从头做到尾？**"

## 2. 三大游戏支柱

参考空之轨迹的支柱（导力器科技世界观、强叙事群像剧、战术性回合制），针对垂直切片规模做了收窄与替换：

### 支柱一：战术性回合制——"每场战斗都是一道小谜题"
**如何体现在玩法中：**
- 速度排序的回合队列（简化版 AT：战斗开始时按速度生成行动顺序，玩家在 UI 上永远能看到接下来 3 个行动的是谁）——这让"我这回合要不要防御"变成有信息依据的决策，而不是赌运气。
- 每种敌人有一个明确弱点属性（火/冰/雷三系足够，不需要更多），克制打击有额外伤害并击退敌人行动位——玩家在遭遇战前能通过"观察"敌人外观推断弱点，战斗中通过尝试验证。
- 三名可操作角色职业互补：物理输出（剑士）、法术输出（术士，主攻弱点属性）、辅助治疗（能防御队友/回复）。一个三人小队就能撑起"攻谁、防谁、奶谁"的完整决策空间。

**为什么是支柱**：这是空之轨迹玩法层面最值得继承的部分，且是三个支柱中"系统复杂度/叙事复杂度"比值最高的一项——用相对少的代码量换来最高的"这是正经游戏不是走路模拟器"的可信度。

### 支柱二：角色驱动的叙事——"剧情在对话里，不在过场动画里"
**如何体现在玩法中：**
- 所有叙事通过游戏内对话事件呈现：城镇 NPC 有日常对话（切剧情阶段后会更新）、队伍成员在特定地点触发"队员聊天"（复刻空轨的角色羁绊感）、关键剧情用头像 + 名字 + 逐字文本框。
- **不做**全屏过场动画、镜头运镜脚本、配音。30 分钟剧情全部用"玩家控制角色走到哪、剧情发生在哪"的 in-world 方式呈现——这既是范围约束，也恰好是空轨早期作品 Charm 值的来源。
- 剧情结构用空轨式的"日常→事件→调查→收束"四拍：切片剧情设计为"小镇委托 → 遗迹异变 → 探索 → 抵达遗迹深处见真章"，结尾留一个钩子（为什么做钩子见风险清单第 4 条）。

**为什么是支柱**：对第一次做游戏的开发者，叙事系统的技术复杂度最低（就是对话事件 + 文本），但它是玩家感知"这是 JRPG 而不是技术 demo"的核心，也是用户本人做这个项目的初心所在。

### 支柱三：小而密的探索——"一张地图，每个角落都有东西"
**如何体现在玩法中：**
- 不追求"大世界"，追求**密度**：一张包含小镇（约 6-8 栋可进建筑、10+ 个有名字的 NPC）+ 一条连接道路 + 一座三层小遗迹的地图组合。宝箱、可调查物品（带 flavor text）、隐藏小路按"玩家每走 30 秒就该发现点什么"的密度摆放。
- 探索奖励与战斗强耦合：宝箱给装备和回复道具，直接改变下一场战斗的难度体感——探索的爽感落在战斗里，而不是落在"收集完成度"数字上。
- 小地图不配导航标记、不配任务列表 UI。方向感靠地图设计本身（道路、地标）——这是空轨式"看地图找路"的体验，也是省掉一个 UI 系统的砍法。

**为什么是支柱**：垂直切片最怕被评审成"技术演示"。密度型探索是最便宜的方法让切片"闻起来像一个完整游戏的开头"。

## 3. MDA 分析

### 机制层（Mechanics——设计师做了什么）
- 网格/自由移动的地图探索（走路、对话交互、开宝箱、调查物件）
- 遇敌方式：**可见敌人**（地图上有敌人精灵，接触触发战斗），非暗雷随机遇敌——理由：可见敌人让玩家有"绕开"的选择权，与支柱一"每场战斗都有选择"同构，且素材包通常自带敌人行走图。
- 回合制战斗：速度排序行动队列、攻击/技能/道具/防御四个基础指令、三系属性克制（伤害 ×1.5 / ×0.5）、简单仇恨与单体/群体目标选择。
- 数值系统：等级经验曲线（切片内预计升 3-4 级）、装备槽（武器/防具各一件，不搞饰品）、消耗品（回复 HP/MP、战斗中可用）。
- 对话事件系统：线性对话、简单分支（仅影响当句回复，不存 flag）、剧情阶段推进（阶段变化会刷新 NPC 对话）。

### 动态层（Dynamics——玩家实际会做什么）
- **观察-验证循环**：看到新敌人外观 → 猜弱点 → 战斗中试一技能验证 → 调整策略。战斗后留下"下次遇到这种怪先打雷"的经验。
- **资源节奏**：遗迹三层是一次连续 push，玩家要在"现在嗑药保安全"和"省着到 Boss 战"之间做取舍；回复道具在探索中可补充，形成"花光→补给→再战"的呼吸节奏。
- **对话狩猎**：玩家在剧情阶段切换后回城镇"重新聊一遍所有人"，期待 NPC 台词更新——这是 JRPG 玩家的经典行为，我们要主动喂养它（至少让 5-6 个 NPC 有阶段二对话）。
- **地图翻找**：沿着"这条路好像能走"的直觉探索，被宝箱和 flavor text 持续奖励。

### 美学层（Aesthetics——玩家感受到什么）
- **战术满足感**（Challenge + Fantasy）：打出弱点克制、在 Boss 战中靠防御时机翻盘的"我赢在脑子"的感觉。
- **怀旧温情**（Narrative + Fantasy）：像素小镇、逐字对话框、NPC 会记得剧情进程——玩家感受到"这是一个被认真对待的小世界"。
- **发现之乐**（Discovery）：每 30 秒有一次小惊喜的探索节奏；遗迹深处揭开悬念的叙事期待。
- **旅行感**（Fantasy）：三人小队在路上的"群像"氛围——靠战斗中的队伍协作台词和路上的队员聊天碎片化地建立，不需要大段剧情。

一句话总结 MDA 推导逻辑：**机制上我们只做了"移动、对话、战斗、数值"四件事，但通过可见敌人、行动队列、弱点克制、NPC 对话刷新这四个具体设计，让玩家动态地进入"观察-取舍-发现"的循环，最终产出"战术满足 + 怀旧温情 + 发现之乐"的目标美学。**

## 4. 垂直切片范围分层（关键交付物）

产能核算：每周 5-10 小时 × 12-16 周 ≈ **90-160 小时总预算**。以下范围按 ~120 小时中值校准，并留 15% buffer。

### Must-have（切片完成的定义，缺一不算 done）
| 系统 | 内容边界 | 预估工时 |
|---|---|---|
| 地图探索 | 小镇 + 道路 + 三层遗迹，共约 4 张地图；行走、碰撞、地图切换、宝箱、可调查物件 | 18h |
| 遇敌 | 可见敌人（4-5 种普通敌 + 1 个 Boss），接触触发战斗 | 4h |
| 回合制战斗最小版 | 速度行动队列、4 基础指令、3 系克制、3 名可操作角色、单体/群体技能、胜利/失败/逃跑结算 | 30h |
| 对话事件系统 | 对话框 UI、逐字显示、线性对话、NPC 交互、剧情阶段刷新 NPC 对话 | 14h |
| 剧情片段 | "委托 → 异变 → 遗迹探索 → Boss 战 → 钩子结尾"完整段落，约 30 分钟，含 2 段队员聊天 | 16h |
| 基础 UI | 菜单（查看状态/使用道具/装备更换）、战斗 UI、对话框——只此三块，不做更多 | 10h |
| 存档/读档 | 单存档槽，地图与事件触发点自动存档 + 菜单手动存档 | 5h |
| 数值平衡与打磨 | 升级曲线、4-5 场战斗的手调难度验证、新手引导（教学对话不超过 1 分钟） | 12h |

Must-have 合计 ≈ **109h**，中值产能下约 3.5 个月，符合窗口。

### Should-have（Must 完成且进度超前时才做，按优先级排序）
1. 战斗中的队伍协作语音文本（触发条件：特定角色组合技/连击）——强化支柱二，纯文本成本。
2. 遗迹内一个简易机关谜题（推块/开关门）——给探索增加一次"啊哈"时刻。
3. 小镇一个迷你支线（找一个走失的猫/道具归还，10 分钟，纯对话+道具）。
4. Boss 战第二阶段（血量阈值触发新技能）——提升压轴体感。
5. 音效接入（战斗音效、UI 音；BGM 用素材包自带）。

### Cut（明确砍掉，写在这里防止 scope creep 回潮）
- ❌ **导力器/技能树全配置系统**——空轨最核心也最贵的系统，垂直切片用"升级自动习得技能"替代；完整版留给正式立项后。
- ❌ 多结局、剧情 flag 分支——切片只有一条线。
- ❌ 钓鱼、料理、收集图鉴等空轨名物支线系统。
- ❌ 队伍编成/第 4 名角色——固定三人组。
- ❌ 全屏过场动画、镜头脚本、配音、Live2D 立绘。
- ❌ 昼夜系统、天气系统、迷你地图、任务日志 UI、成就系统。
- ❌ 装备合成/强化、饰品系统、异常状态深水区（只保留"中毒"一种，用来教玩家用道具）。
- ❌ 随机暗雷遇敌（被可见敌人替代，见 MDA 层理由）。

**范围裁决原则（写给未来的自己）**：任何新增想法先问两个问题——"它服务于三大支柱中的哪一条？"和"砍掉它，30 分钟的切片体验会崩吗？"两个问题有一个答不上来，就进 Cut 清单。

## 5. 视觉锚点（供林绘澄/art-director 接手）

1. **《英雄传说：空之轨迹 FC》原版（2004）**——学什么：整体氛围基调、对话框排版（名字栏 + 文本 + 底部提示）、城镇"小而有人味"的 NPC 摆放密度。不学什么：原版 3D 建模精度（我们用 2D 像素替代）。
2. **《八方旅人 Octopath Traveler》**——学什么：HD-2D 式的 2.5D 呈现思路——像素角色 + 透视俯视地图 + 光影纵深。切片哪怕只做到"俯视地图 + 轻微透视 + 一层光照"，气质就已经对。这是本次美术方向的第一参考。
3. **《Chained Echoes》（单人体量独立 JRPG 标杆）**——学什么：单人/小团队 + 素材组合所能达到的完成度上限；它证明"风格统一比素材精美更重要"。
4. **《星之海 Sea of Stars》**——学什么：回合制战斗的呈现节奏——技能施放的短暂定格、受击反馈、Boss 出场排面。战斗打击感的第一参考。
5. **素材包家族约束**：建议锁定单一艺术家/单一风格家族的素材包（例如 itch.io 上单一作者的 top-down pixel 资源全家桶：角色行走图 + tileset + 敌人 + UI 九宫格），禁止跨风格混搭。这是给美术侧的硬约束，理由见风险清单第 2 条。

## 6. 风险清单：第一次做 JRPG 的五个死法与规避

### 坑 1：导力器陷阱——先做系统，后做游戏（最高危）
症状：花两个月做一个可配置技能/装备/合成系统，做完发现没有内容用它。
**规避**：铁律——**内容先于系统**。每个系统的立项顺序由剧情片段的需求倒推：切片剧情用不到的系统一律不做。本概念文档的 Must-have 清单就是这个铁律的落地。

### 坑 2：素材包风格混杂，游戏看起来像缝合怪
症状：A 包的角色 + B 包的地图 + C 包的 UI，色板和像素密度对不上，成品一眼廉价。
**规避**：立项第一周就锁定单一素材家族（见视觉锚点第 5 条）；所有新素材需求（如拼不出的 tile）先尝试在同一家族内用现有元件改色解决。此项作为美术选型（TASK-02）的验收标准之一。

### 坑 3：战斗系统无限打磨
症状："手感还不够好""数值再调调"，在只有一场战斗的 demo 里迭代到第 20 版，项目死在打磨里。
**规避**：给战斗系统定义客观的 done 标准——**5 场手工调校的战斗全部通过"三问测试"**：玩家会不会用防御？（会）玩家会不会切换目标/属性？（会）有没有至少一场让测试者说"这场有点意思"？达标即冻结，进入内容制作。

### 坑 4：剧情文案膨胀 + 结尾烂尾
症状：开头写得酣畅，世界观越写越大，30 分钟切片装进 3 小时文案；或者结尾仓促，玩家觉得"就这？"
**规避**：给切片剧情定死字数预算（对话框计，约 250-350 条对话文本）；结构上采用"四拍 + 钩子"——钩子是**一个未解之谜，不是未完成的剧情**。契约：切片结尾允许悬念，不允许"做到这里工期不够了"式的戛然而止。

### 坑 5：弃坑螺旋——看不见的工程吃掉热情
症状：存档、UI、碰撞、地图切换这些"无聊但必需"的部分被无限推迟，进度感归零，第 6-8 周弃坑（业余项目弃坑的典型时间窗）。
**规避**：① 把 Must-have 清单按 2 周一个里程碑重排，每个里程碑结束时切片必须"能玩"（哪怕丑）；② 每 2 周给朋友/用户自己录一段 5 分钟试玩视频留档——进度可视化是对抗弃坑最有效的药；③ UI 和存档不放在"最后再说"，在里程碑 3（第 6 周）就必须存在。
