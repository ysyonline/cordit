# 《轨迹残响》UI 布局规格（战斗 / 对话 / 主菜单）v1.0

> 作者：林绘澄（art-director）｜阶段：Phase 2 系统设计收尾（TASK-06）｜版本：v1.1（v1.0 冻结后按开源素材方案修订素材口径，布局坐标零变更；明细见 `design/art-bible/revision-ui-specs.md`）
> 硬约束：视口 640×360（ADR-4）、Nearest 过滤、整数缩放、整数坐标、五色板（羊皮纸 #E8DCC0 / 赤陶红 #A6423A / 徽章金 #D9A94E / 橄榄绿 #6B8E4E / 暖灰紫 #4A3B52）、中文用 Fusion Pixel 像素字体。

## 0. 全局字体与层级约定（三份规格共用）

### 0.1 字号体系（Fusion Pixel，全部整数号）
| 用途 | 字号 | 1080p 实显（×3） | 说明 |
|---|---|---|---|
| 窗体标题 / 升级提示 / 克制弹字 | 16px | 48px | 仅强调用，正文禁用 |
| 对话正文 / 菜单项 / 数值标签 | 12px | 36px | **默认正文字号** |
| HP/MP 数值 / 敌名小标签 | 8px | 24px | 数字与短标签专用 |

可读性论证：Fusion Pixel 的中文字形按 12px 网格设计（5×9~12×12 点阵），12px 是其"原生可读下限之上最舒适档"；在 640×360 下 12px 经整数 ×3 后为 36px 屏显，远超可读性要求，且因 Nearest+整数缩放不会产生字形糊边。8px 档仅用于 0-9 数值与 2 字短标签（数字点阵简单，24px 屏显可读），**禁止 8px 排长句**。

### 0.2 通用绘制规则
- 所有窗口 = 自制五色板窗体框 + 9-slice（详见第三节 3.2），内底 #E8DCC0，窗体描边深色取 #4A3B52 系。
- 文字统一带 1px 投影 #4A3B52（除深底上的白字可免）。
- 置灰 = 文字色 #8E7F98（#4A3B52 减饱和提亮派生，不引入新色相）+ 底色压暗，**不透明度不用小数**（用预混色实现）。
- 浮动动画（弹跳、上升）全部按整数像素步进，帧率可以是小数，**位置不可以**。

### 0.3 画面 Z 序（战斗）
背景(0) → 敌我战斗精灵(1) → 敌方头顶信息(2) → 浮动数字(3) → 指令/状态 UI 窗口(4) → 目标光标与预估伤害(5) → 系统光标(6)。

### 1.1 行动预告条（顶部横排）
- **位置/尺寸**：右上角贴边。三槽各 40×44，槽间距 4px。总占位 (504, 8, 128, 44)。
  - 槽 1（当前行动者）：(592, 8, 40, 44)；槽 2：(548, 8, 40, 44)；槽 3：(504, 8, 40, 44)。
- **层级**：Z4，战斗中常驻。
- **结构**：每槽 = 32×32 头像区：我方角色取 **48×48 Faces（CharlesGabriel，CC-BY 3.0）裁切眉眼区**出 32×32——48→32 为非整数倍，**禁缩放、只裁切**；敌人取战斗精灵 16×16 **×2 整数放大**（Nearest，无插值）+ 1px #4A3B52 描边。槽底部 8px 名字小标签（超 3 字截断）。
- **当前行动者高亮**：2px 徽章金 #D9A94E 描边 + 整槽提亮一档（预混色）；非当前槽 1px #4A3B52 描边。不用缩放动画（保持整数）。
- **我方/敌方底色区分**：我方槽底 #E8DCC0（羊皮纸，深字）；敌方槽底 #4A3B52（暖灰紫，白字）。双通道编码：底色 + 敌方槽顶部 4px 赤陶红 #A6423A 色条（色弱可用形状/色条区分，不单靠色相）。
- **行为**：常驻显示接下来 3 个行动；击退/死亡后立即重算刷新（对齐战斗 GDD 3.1）；队列不足 3 人时剩余槽显示空槽框（1px #4A3B52 虚线框）。
- **素材来源**：我方头像取 48×48 Faces 1st Sheet（CharlesGabriel，CC-BY 3.0）；敌方头像取 OGA 敌人包精灵（Redshrike，CC-BY 3.0）；槽框为 9-slice 自制窗体框最小档。
- **缺件补位**：怪物头像 = 战斗精灵头部区域 ×2 整数放大 + 1px 描边（原"32×32 裁切"口径随 16×16 精灵尺寸废弃）。

### 1.2 指令菜单（左下）
- **位置/尺寸**：(8, 234, 104, 118)。窗体 9-slice，内底 #E8DCC0。
- **层级**：Z4，仅在轮到玩家角色时弹出；敌方回合隐藏。
- **条目**（5 行 × 22px 行高，12px 字，内边距上下各 4px）：攻击 / 技能 / 道具 / 防御 / 逃跑。
- **状态表现**：
  - 正常：深棕字，行首光标 ▶（徽章金）。
  - MP 不足 / 不可用（GDD 边缘情况 4/5）：整行置灰 #8E7F98，光标跳过该行；"道具"耗尽时行内改显"无道具"8px 小字。
  - Boss 战：第 5 行"逃跑"置灰（对齐战斗 GDD）。
- **键盘操作流**：↑/↓ 在可用项间移动（跳过置灰项）→ Z/Enter 确认进入目标选择或子菜单 → X/Esc 取消返回上一层（对齐 GDD"可随时取消重选"）。子菜单（技能列表/道具列表）复用同窗体，在指令菜单右侧弹出 (120, 234, 176, 118)，超出 9 项时 8px 行高滚动。
- **素材来源**：窗体框 9-slice 自制；光标 ▶ 用 Kenney CC0 光标元素或全自绘。
- **缺件补位**：无现成光标元素则用 8×8 金色三角自绘（#D9A94E + 1px #4A3B52 描边）。

### 1.3 我方状态栏（底部）
- **位置/尺寸**：(120, 296, 512, 56)。三个面板各 168×56，间距 4px：面板 1 x=120、面板 2 x=292、面板 3 x=464。与指令菜单水平错开（菜单占 x8~112），不重叠。
- **层级**：Z4，战斗中常驻。
- **面板结构**（面板内相对坐标）：
  - 名字：12px，(8, 6)。
  - 中毒角标：12×12 绿色泡状图标，面板右上角 (152, 4)，出现时轻闪 2 帧提示。
  - HP 条：(8, 24, 88, 6)，底槽 #4A3B52，填充 #A6423A（赤陶红=生命主色）；≤25% 时填充转徽章金 #D9A94E 并闪烁。数值 "120/120" 8px，条右侧 (100, 22)。
  - MP 条：(8, 40, 88, 6)，填充 #6B8E4E（橄榄绿）；数值 8px 同 HP 位式。
  - HP/MP 识别不单靠颜色：条前带 8px 字母标签 "HP"/"MP"（可访问性）。
- **行为**：数值变化滚动显示（每帧 ±2 整数步进）；角色死亡 → 整面板置灰 + 名字后加"倒"8px 角标。
- **素材来源**：条底/填充为纯色矩形（1×1 拉伸，Nearest 下无变形问题），无素材依赖；中毒图标自绘。
- **缺件补位**：中毒泡状图标自绘 12×12 绿泡为主方案（DawnLike 如有适用图标可取用后统一校色）。

### 1.4 敌方头顶信息
- **HP 条**：40×4，位于敌精灵头顶上方 8px（随精灵 y-sort 走）。底槽 #4A3B52，填充 #A6423A。
- **显示规则**：受击时淡入（2 帧），持续 3 秒后 0.5 秒淡出（透明度分 4 档整数阶：100/75/50/25/0，避免逐帧小数）。多个敌人各自独立计时。
- **弱点图标**：12×12，位于 HP 条右侧 4px。按战斗 GDD 3.3 三步规则出现：首克命中后本场常驻；同存档后续战斗常驻。图标 = 火/冰/雷三枚 12×12 宝石形（火 #A6423A、冰 #E8DCC0、雷 #D9A94E，各带 1px #4A3B52 描边）。
- **素材来源**：OGA 敌人包（Redshrike，CC-BY 3.0）自带各敌精灵；HP 条纯色自绘。
- **缺件补位**：三系宝石图标无现成来源 → 自绘（合计 36×12 一张图集），调色严格取五色板。

### 1.5 目标选择光标 + 预估伤害区间
- **光标**：16×16 倒三角（徽章金填充 + 1px #4A3B52 描边），位于当前目标头顶上方 24px（敌 HP 条再上方 12px），2 帧上下浮动 ±2px（整数步进）。左右键在可选敌人间循环，Z 确认、X 取消（我方目标选择时上下键切换队友）。
- **预估伤害区间**："— 24~29 —" 格式，12px 白字 + 1px #4A3B52 投影，显示于目标精灵脚下 y+8 处（避免与头顶 HP 条打架）。数值取伤害公式浮动端值 0.9/1.1（对齐战斗 GDD 4.5），抗性/弱点倍率实时计入——这是玩家验证克制的 UI 工具。
- **防越界**：文字锚点居中于目标，但 clamp 到 x∈[4, 636−文本宽]。
- **素材来源**：光标自绘（同 1.2 补位方案）；文字为字体渲染。

### 1.6 浮动数字色彩映射
| 类型 | 颜色 | 字号 | 附加表现 |
|---|---|---|---|
| 普通伤害 | 白 #FFFFFF + 1px #4A3B52 描边 | 12px | 上浮 24px / 0.6s（4px 步进） |
| 克制 | 徽章金 #D9A94E + 描边 | 16px（≈1.3 倍，取整数字号） | 上浮同时 2 帧 pop（先上冲 8px 再回落），伴随"弱点！"16px 金字在数字上方弹出 |
| 抗性 | 灰 #8E7F98 | 12px | 上浮减半（12px），节奏更"钝" |
| 回复 | 橄榄绿 #6B8E4E + 描边 | 12px | 上浮同普通，数字前带 "+" |
| MISS | — | — | 本系统无命中判定，不实现 |

说明："克制橙"在本项目映射为徽章金 #D9A94E——五色板内最接近橙的强调色，且与"标题/稀有度"用法语义相容（克制=高光时刻）。克制识别不单靠颜色：字号放大 + "弱点！"弹字构成三通道（色/形/文），色弱玩家可辨。
- **生成位**：目标头顶（敌）或状态面板上方（我方受击/回复，从面板上缘弹出，不遮挡数值行）。
- **素材来源**：纯字体渲染，零素材。

### 1.7 结算画面
- **位置/尺寸**：(160, 84, 320, 192)，居中窗体 9-slice，内底 #E8DCC0。背景压暗：全屏 #4A3B52 α50%（预混 4 档阶跃）。
- **结构**（窗内相对坐标）：
  - 标题"战斗胜利"：16px 徽章金，居中 y=16。
  - EXP 行区：y=48 起，逐条弹出（每 0.4s 一条，弹出 = 上冲 8px 落定 + 短音效）："凯尔 EXP +12" 12px，每角色一行；金币不设（切片无商店）。
  - 掉落区：y=112，16×16 道具图标 + 12px 道具名（掉落全 100% 单一道具，只留一行）。
  - 升级行：y=144 起，逐条弹出，16px 徽章金："莉娜 Lv2！习得【火球】"（接口 I4 多级连升：逐条排队展示，Z 键跳过动画直接全显）。
  - 底部提示："Z 关闭" 8px，右下（窗口内 y=180）。
- **素材来源**：道具图标取 DawnLike 物品图标（CC-BY 4.0）或 OGA 16x16 Item-Icons；窗体同 9-slice。

### 1.8 战斗背景实施规格
- **来源**：遇敌瞬间对当前地图做一次全屏截图（战斗系统提供触发接口），战斗期间为静态纹理，不逐帧重截。
- **模糊（推荐管线，零着色器成本）**：截图 640×360 → 降采样至 160×90 → 双线性放大回 640×360。等效 4px 高斯模糊，天然保留原调色板与像素颗粒感，比实时 blur 着色器便宜且风格更贴。备选：Gaussian blur 半径 4px（@640×360），效果相近但需着色器，非必要不用。
- **暗角**：全屏叠加径向渐变层，中心透明 → 四边 #4A3B52，边缘最高 α65%（预混 4 阶：0/25/45/65，不用连续小数渐变以贴合像素风）。另在底部 y=296~360（状态栏带）额外压暗一档，保证 UI 文字对比度。
- **素材来源**：运行时截图，无包素材。

## 二、对话框布局规格

### ASCII 示意

```
 (对话框区: 窗体 (16,244,608,108))
┌────────────────────────────────────────────────────────────┐
│┌名字栏────┐                                                │
││ 凯尔     │  本轮对话文本最多两行半，12px Fusion Pixel，    │
│└──────────┘  单行约40汉字，自动折行……                      │
│┌────────┐                                                  ▼│
││ 头像    │   第二行文本……                                   │
││ 48x48  │                                                   │
│└────────┘                                                  │
└────────────────────────────────────────────────────────────┘
        ↑ 选项时在对话框上方右侧弹出选择窗 (448,168,176,68)
```

### 2.1 结构与坐标
- **主体窗体**：(16, 244, 608, 108)，9-slice，内底 #E8DCC0，下边距屏幕 8px。
- **名字栏**：子窗体 (24, 224, 96, 20)，底色赤陶红 #A6423A，白字 12px 左对齐（内缩 4px）。压在主体窗上沿（Z 高一级）。
- **头像窗**：左侧内嵌 (24, 252, 88, 88)：**48×48 面部头像居中**（CharlesGabriel faces 原生 48×48，零缩放，×3=144px 整数屏显），1px #4A3B52 内描边框；窗体 88×88 不变，仅内框适配（描边框 1px 包住 48×48，即 mockup 已验证的 (39,261)–(89,312) 框方案）。原 64×64 显示口径废弃（64 = 48×4/3 非整数放大，禁）。
- **文本区**：x 从 128 到 612（宽 484px），行高 18px，三行基线 y = 268 / 286 / 304。**≤2 行半**：第三行只允许显示上半截渐隐尾行（预混色阶），视觉上提示"还有下一条"。
- **容量核算**：484px ÷ 12px/汉字 ≈ 40 字/行 → 单条上限 60 汉字必然 ≤2 行，自动折行按"标点避头尾 + 词组优先"简单规则（每行 40 字硬折即可）。
- **头像差分切换**：同一角色的 normal/talk/hurt 等 Faces 头像差分在打字机过程中按事件标记切换（打字机 2 字/帧）。无立绘路线，情感浓度靠差分 + 文字节奏。
- **继续箭头**：▼ 8px 徽章金，(600, 336)，0.5s 周期闪烁。Z/Enter 翻页，X 无效（对话不可跳回）。
- **选项列表**：窗体 (448, 168, 176, 68)（对话框上沿 244 − 8 间距 − 68 窗高 = 168，不越界）。最多 2 项 × 行高 24px + 上下边距 20px。↑/↓ 移动、Z 确认、X 取消（X 视事件定义为"取消/默认项"）。光标 ▶ 同主菜单。

### 2.2 中文字号建议与可读性论证
- **正文 12px**：640×360 下 40 字/行的信息密度接近 SNES JRPG 原生体验（空之轨迹 PC 版约 38 字/行），×3 整数缩放后 36px 屏显。Fusion Pixel 12px 档的汉字点阵完整无省笔画。
- **不采用 16px 正文**：16px 时每行仅 30 字，同样 60 字要 2 行打满 + 频繁翻页，阅读节奏碎；且 16px 在本视口偏"巨大"，破坏 2.5 头身 chibi 的画面比例感。16px 保留给强调场景（标题/升级）。
- **名字栏 12px**：名字最长 2~3 字，用 12px 而非 8px，保证辨识。
- **禁项**：任何非整数号（如 10px 会触发点阵重采样糊字）、任何非整数缩放。

### 3.1 结构与坐标
- **指令菜单窗**：(16, 16, 96, 136)。5 项（状态/道具/装备/存档/读档）× 行高 24px + 内边距 16px。12px 字，↑/↓ 移动（跳过置灰项：无存档文件时"读档"置灰），Z 确认，X/Esc 关闭菜单。
- **角色状态面板**：(128, 16, 496, 328)。三个角色块各 480×96，纵向排列，块顶 y = 32 / 136 / 240。
  - 块内：48×48 脸部头像左侧 (8, 24)；名字 12px (64, 8)；"Lv2" 8px (64, 28)；HP/MP 条 120×6 + 8px 数值 (200, 20) / (200, 44)，条色与战斗状态栏一致；ATK/MAG/DEF/SPD 面板值 8px 两列 (352, 20) 起。
  - 死亡（HP0）角色块整块置灰 #8E7F98。
- **子界面**（道具/装备）：复用 9-slice 窗体，在状态面板区弹出同尺寸窗口；道具列表 8 行滚动。存档/读档：3 槽列表窗 (184, 108, 272, 144) 居中（(640−272)/2=184）。
- **素材来源**：头像 = 48×48 Faces（原生 48×48 零缩放）、窗体框、光标同前；图标（道具/装备）取 DawnLike 或 OGA 16x16 Item-Icons。
- **缺件补位**：装备位图标（武器/防具）若缺 → 16×16 自绘剑/盾剪影（#A6423A + #D9A94E 两种色差分区分栏位）。

### 3.2 9-slice 窗体框实施说明
- **取材**：**全自制两套五色板窗体框**（标准主窗 + 赤陶红名字栏变体）；可选底稿 = Kenney ui-pack-rpg-expansion（CC0）重上色为五色板后切分。四角 16×16 / 边条 16×16 / 中央填充的自制规格与 RPG Maker windowskin 布局对齐，便于未来换源。
- **切分边距**：四边各 **8px**（素材 1x 分辨率下；四角 8×8 保留窗框圆角/花纹，边条 8px 宽）。
- **绘制规则**：
  1. 四角 1:1 原样绘制，禁止缩放（花纹像素不可变形）。
  2. 边条用 **tile 平铺**而非拉伸（Godot NinePatchRect 默认拉伸，需关掉 stretch 边改 tile 模式，或用自建 3×3 场景实现），防止边框花纹被非整数压缩。
  3. 中心填充：优先用自制中央填充块平铺；简化方案为纯色 #E8DCC0 矩形 + 自制细纹理平铺。
  4. 描边/阴影色统一 #4A3B52（五色板），高光/内描统一 #D9A94E，不做包内取色。
- **产出物**：一张标准窗体框 + 一张"红色名字栏"变体，全项目所有窗口仅用这两套 9-slice，禁止每窗一框。
