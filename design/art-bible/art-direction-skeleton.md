## 一、素材包选型建议

前提约束：每周 5-10 小时、非美术背景、目标 30 分钟垂直切片（城镇/野外 + 回合制战斗 + 剧情）。因此选型第一原则是**"单一作者、成套出品"**，宁可风格朴实但全套自洽，不要东拼西凑的高颜值散件。

### 候选 1（原★首选｜〔已被开源方案替代，仅作风味参照〕）：Time Fantasy 系列（finalbossblues，itch.io，付费约 $10-20/包，常有限时全包 bundle）
- **风格**：SNES 时代经典 JRPG 血统，16x16 tile、2 头身 chibi 角色、暖色厚涂感像素——与"空之轨迹式暖色王国风"是直系血缘。
- **覆盖度**：城镇/室内/野外/地城 tileset + 角色行走图 + 面部头像 + 怪物包 + 战斗背景，是目前候选中唯一"一套买完基本齐活"的。
- **适配度评分：9/10**。理由：单一作者、单一调色板体系、角色/场景/UI 天然同源，对业余开发者来说维护视觉统一性的成本最低。且该系列兼容 RPG Maker 生态，未来转引擎也不浪费。

### 候选 2：ProtoSeries（SlightlyNerd，itch.io，多为 $3-10/包）
- **风格**：16x16 现代 JRPG 模块化小包，干净利落，偏冷色中性。
- **覆盖度**：室内/城镇/装饰散件丰富，但角色与怪物需要跨多个包拼。
- **适配度：7/10**。优点是便宜灵活；缺点是模块化组合恰恰是视觉违和的高发区，对没有美术功底的人不友好。

### 候选 3：Mystic Woods（Game Endeavor，itch.io，约 $20）
- **风格**：16x16，吉卜力式自然风光，颜色明快，观赏性最高。
- **覆盖度**：野外/村庄很出色，但**城镇室内、回合制怪物、战斗 UI 支撑薄弱**。
- **适配度：6.5/10**。适合做"野外补充包"而不是主包；单独用它做完整切片会缺件。

### 候选 4：LimeZu Modern Interiors / Serene Village（itch.io，付费 $7-15，另有免费版）
- **风格**：16x16，无描边干净风，但**现代题材**（家电、沙发、便利店），幻想王国感弱。
- **适配度：5/10**。除非概念改走现代/都市 JRPG，否则不推荐。免费版可用于原型验证期，正式期不建议。

### 明确推荐（2026-08 修订：开源方案生效）
**首选 OGA 16x16 JRPG 系列**（opengameart.org 官方委托集，BartK/Orange Engine，多作者但明确 designed to work together）：以 surt 城镇/森林/神殿 tileset（CC0）+ MrBeast 洞穴/下水道 tileset（CC-BY 3.0）+ Redshrike 敌人包（CC-BY 3.0）+ Antifarea/CharlesGabriel 16x18 角色与 48×48 面部（CC-BY 3.0）为主集；**DawnLike**（DragonDePlatino，CC-BY 4.0）作怪物/物品图标补充池；**Kenney ui-pack-rpg-expansion**（CC0）作 UI 窗体框底稿（重上色为五色板）。
**Time Fantasy 降为风格参照板**：不购买，仅截图对标气质（保留上方候选评分作历史记录，标注"已被开源方案替代"）。
理由：许可洁净（零 CC-BY-SA/GPL 入库）、16×16 网格与 ADR-4/全部冻结产物零冲突（0 重做/4 小改）、画风经 mockup 目验过关（`mockup/town-street-mockup.png`）。

**遗迹三层 tileset 指定（许可已核实，无降级路径）**：
- 遗迹一层（砖墙水道）= Sewer tileset（MrBeast，CC-BY 3.0）
- 遗迹二层（洞窟）= Cave tileset（MrBeast，CC-BY 3.0）
- 遗迹三层 / Boss 房（遗迹核心）= **Classical Temple Tiles（surt，CC0**，opengameart.org/content/classical-temple-tiles，页面许可栏直接标注 CC0，已核实）——"古典神殿废墟"主题成立，原"待核实/降级"项就此关闭。

**草地取材指定**：surt 城镇表全表仅 1 块 16×16 纯草地，草地/植被一律从 **forest_tiles（surt，CC0）** 取材——两者为官方配套设计（城镇页明确互链），统一性有保障。

## 二、视觉身份·前三节骨架

### 第 1 节：视觉锚点（3-5 个，与概念文档对齐）
1. **《英雄传说：空之轨迹 FC/SC》**——斜俯 3/4 视角、暖色王国城镇、精致小场景叙事（NPC 摆设讲故事）。核心锚点。
2. **《时空幻境 Phantasia / SNES 期 Namco JRPG》**——OGA 16x16 JRPG 系列（风格对标 Time Fantasy / SNES JRPG）的原生审美区间，参考其 UI 与战斗演出质感。
3. **《星露谷物语》**——证明"单一作者成套像素素材 + 暖色调"可以承载长线情感叙事，作为亲和力参照（非玩法参照）。
4. **Bokuden/王道剑与魔法插画构图**——战斗背景的远景构图参照（雪山、城堡剪影、暖阳），不用自绘，只借构图语言。

### 第 2 节：风格基调
- **视角约定**：Top-down 3/4（斜俯），tile 平铺、纵向无透视收缩，纵深靠 y-sort 排序表达。**明确排除 45° 等轴（isometric）**——等轴素材包少、行走图适配差，与主流素材生态不符。
- **比例**：16x18 ≈ 2.5 头身 chibi 系（Antifarea 规格，OGA 16x16 JRPG 系列角色），拒绝 3 头身以上写实比例（如 LPC 32×32 系）——比例混用是混包第一大违和源。
- **光照氛围**：白天顶光、光源统一左上；切片内以"晴朗白天 + 一个黄昏/傍晚剧情时刻"为氛围上限，不做动态昼夜光照（超出素材包能力，留给未来）。

### 第 3 节：配色方向
推荐**"暖色王国风"**，直接对齐空之轨迹的里·王都气质：
- 基底：暖米白 / 羊皮纸色（#E8DCC0 系）—— UI 与过场底色
- 主色：赤陶红 / 砖红（#A6423A 系）—— 王国旗帜、UI 强调、危险反馈
- 辅色：徽章金（#D9A94E 系）—— 边框、稀有度、标题
- 环境绿：橄榄绿（#6B8E4E 系）—— 野外，压低饱和避免与主色打架
- 夜色/阴影：偏紫的暖灰（#4A3B52 系），不用纯黑
- 原则：素材包自带色优先，调色仅做局部 hue-shift 校准，不做大改（保持包内调色板一致性）。

## 三、混用素材"统一性守则"（硬规则）

1. **网格分辨率唯一**：全场 16x16 tile 网格，所有素材按整数倍（×3 或 ×4）统一缩放进引擎，禁止非整数缩放和不同倍率混排。
2. **比例唯一**：角色一律 16x18 ≈ 2.5 头身 chibi 系。任何 3 头身以上的素材（如高个子 NPC 包、立绘比例素材）不入战斗/行走图层，只允许出现在对话头像框等"独立容器"里。
3. **描边政策（分层豁免制）**：角色/精灵层以 Antifarea 深色描边系为基准；环境 tile 层允许无描边（surt 系），即**"角色描边/环境 tile 不强制"豁免**。同一图层内仍禁止描边风格混用。
4. **光影方向与调色板饱和度对齐**：光源统一左上；新素材若整体饱和度/明度明显偏离主包，先做 palette shift 再入库。
5. **来源登记制**：每个资产在清单里登记来源包，孤立来源（只用过一次、与其他包风格相邻的素材）标记为"高危违和点"，优先替换。

### 校色规范（三则，源自 mockup 拼合实测）
1. **色温对齐**：三套素材底色（Antifarea 角色表 239,208,116 / 面部表 255,238,207 / 羊皮纸 #E8DCC0 232,220,192）同属暖调家族，与五色板天然亲和；拼合**不做整体 palette shift**，仅做逐资产目验。
2. **角色层轻提亮一档**：Antifarea 角色描边偏深，入库时对角色/精灵层做一档轻提亮（预混色实现，保持整数）以贴合场景明度；场景层不动。
3. **偏离即审**：新补充资产（DawnLike 等）入库前按守则 4 做饱和度/明度目验，明显偏离先 palette shift 再入库。

## 四、可行性提醒：素材包路线的常见缺口与补位

| 缺口 | 风险 | 补位方案 |
|---|---|---|
| **UI（菜单/战斗界面）** | 多数 tile 包不含成套 UI | 全自制五色板窗体框 + 9-slice（底稿可取 Kenney CC0 重上色）；像素字体选免费中文像素字体（如 Fusion Pixel / Zpix），禁用系统字直接上高清 |
| **战斗背景** | 开源路线无成套战斗背景 | 降级方案：**放大模糊当前地图截图 + 暗角渐变**（空之轨迹式"战场即场景"的廉价实现），切片阶段够用且风格天然统一 |
| **过场立绘** | 素材包几乎不含全身立绘 | 垂直切片**不做立绘**，用面部头像 + 文本框；把情感浓度做在头像差分与文字节奏上，不硬凑 |
| **技能/魔法 VFX** | 需单独找 | 免费像素特效包（itch.io 大量 CC0 弹幕/魔法 VFX）+ 统一调色为上面四色即可 |
| **过场 CG/开场动画** | 完全无来源 | 用静态 tileset 场景 + 镜头平移 + 文字卡实现"分镜式开场"，这是素材包路线的标准替代 |

**一句话结论**：OGA 16x16 JRPG 系列主集 + 战场即场景 + 头像式对话，是当前约束下视觉一致性最强、补位成本最低、许可最洁净的路线；视觉锚点细节等概念文档（TASK-01）定稿后升级为完整美术圣经。
